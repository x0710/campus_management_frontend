# 校园管理平台使用手册

适用对象：党员、支部负责人、学院党委工作人员、学校党委工作人员及系统管理员。  
编写日期：2026 年 11 月 4日。根据当前项目页面和操作逻辑编写；实际可见菜单及可操作数据以本人账号权限和部署版本为准。

## 一、先看这里：常用操作速查

| 我要做什么 | 从哪里进入 | 怎么操作 |
| - | - | - |
| 申报活动加分 | 党员端 → 成绩申报 | 选择申报类型，填写分数和理由，上传材料，点击「我要申报」 |
| 查看申报结果 | 党员端 → 成绩申报 → 我的申报记录 | 点击对应记录，查看审核进度和审批意见 |
| 审核加分申请 | 党委支部端 / 党委学院端 → 审核管理 | 打开申请，核对理由和附件，填写意见后通过或驳回 |
| 把申请交给其他人 | 审核管理 → 申请详情 → 转交 | 搜索并选择接收人，填写意见，确认转交 |
| 查找支部成员 | 党委支部端 → 支部管理 | 选择组织（如有组织树），搜索成员，点击记录查看详情 |
| 查找学院下属支部成员 | 党委学院端 → 学院支部管理 | 在组织树选择支部，查看成员列表 |
| 配置加分项目及审批人员 | 党委学院端 → 指标 | 新增指标，再进入详情配置审批步骤 |
| 查看学校组织统计 | 党委学校端 → 总览 / 组织概览 | 查看排名，或选择组织查看下级统计 |
| 修改自己的密码 | 右上角姓名 / 头像 → 重置密码 | 输入旧密码和两次新密码，确认 |
| 反馈系统问题 | 顶栏 → 问题上报 | 新建反馈，填写类别、标题、问题描述和联系方式 |


**第一次使用，先完成登录和修改初始密码。审核老师可直接阅读第四章。**

## 二、登录与页面说明

### 2.1 登录系统

1. 打开管理员提供的系统网址。

2. 输入管理员分配的用户名和密码。

3. 点击登录，等待进入工作页面。

4. 如果出现首次登录修改密码窗口，输入当前初始密码、新密码和确认密码，提交成功后继续使用。

首次改密窗口必须完成后才能继续操作。两次新密码必须一致。

「记住用户名」只记住账号名称，不代表记住密码。忘记密码时请联系管理员重置，登录页没有自助找回密码入口。

### 2.2 找到正确的工作端

登录后，系统会根据账号角色进入相应工作端。拥有多个工作端权限时，点击**左上角当前工作端名称**进行切换。

| 工作端 | 主要用途 |
| - | - |
| 党员端 | 个人加分申报、查看成绩记录和个人档案 |
| 党委支部端 | 支部统计、加分审核、支部成员查询 |
| 二级党委端 | 学院统计、指标配置、加分审核、学院支部查询 |
| 学校党委端 | 全校统计、组织成员管理、岗位及系统权限管理 |
| 管理端 | 用户与账户、角色权限、组织架构、岗位管理 |


只有一个可访问工作端时，不显示工作端切换按钮。看不到某个入口时，先核实当前工作端，再联系管理员检查角色授权。

当前版本的学生端、教师端、领导端已停用。教师办理党建业务时，请使用账号已有的党委相关工作端。

### 2.3 页面怎么用

- **左侧菜单**：切换当前工作端的功能。

- **左上角工作端名称**：切换可访问的工作端。

- **右上角姓名 / 头像**：打开个人菜单，可修改密码；支部、学院、学校端还可从这里进入「我的」。党员端的「我的」在左侧菜单中。

- **铃铛图标**：查看消息通知。

- **问题上报**：提交使用问题。

- **「中 / EN」和太阳 / 月亮图标**：切换语言和明暗主题。

- **退出图标**：退出当前账号。

列表中找不到记录时，先清除搜索和筛选条件，再检查其他页。页面有「刷新」按钮时，可点击获取最新结果。

## 三、党员个人操作

### 3.1 提交加分申报

**入口：党员端 → 成绩申报。**

1. 在「申报类型」中选择对应项目。可输入名称或编码搜索，停止输入约 1 秒后显示搜索结果。

2. 阅读右侧「加分细则」，确认本人材料符合要求。

3. 填写「申请加分」。分数应依据所选项目细则填写。

4. 填写「申请理由」，说明活动、时间及申请依据，最多 200 字。

5. 点击「上传附件」，选择证明材料；单次申报最多 10 个附件。等待需要提交的文件全部上传成功。

6. 核对类型、分数、理由和附件，点击「我要申报」。

7. 出现「申报提交成功」后，在下方「我的申报记录」中核对本次记录。

申请理由示例：

> 参加×月×日支部主题党日活动，按本项目加分细则申请×分，附件为活动签到记录和现场照片。

\*\*上传附件后仍需点击「我要申报」，才完成本次申请。\*\*附件是否必须、应提交何种证明，以项目细则为准。

当前成绩申报页面没有撤回、编辑或删除已提交申请的入口。发现填错时，记录申报编号并联系审核人员处理，避免重复提交。

### 3.2 查看审核结果

**入口：党员端 → 成绩申报 → 我的申报记录；也可从首页近期记录进入。**

1. 找到需要查询的申报。

2. 点击记录，进入申报详情。

3. 查看申请内容、附件、审批进度及审批意见。

| 状态 | 含义 | 接下来怎么办 |
| - | - | - |
| 审核中 | 审批流程尚未全部完成 | 等待后续审核，可进入详情查看进度 |
| 申请成功 | 所有必要审批环节已完成 | 核对核定分数和成绩记录 |
| 被驳回 | 审核未通过 | 阅读审批意见，按意见准备材料；需要重新申报时提交新申请 |


\*\*某一环节显示「已通过」，不一定代表整条申请已完成。\*\*请以申请整体状态为准。「申请加分」是本人申报值，「核定分数」是审核确定的值。

### 3.3 查看档案、成绩和审批指南

**入口：党员端 → 我的。其他党委端可通过右上角姓名 / 头像 → 我的进入。**

- 「我的档案」：查看基本资料、所属组织及党员信息。需要修改时，使用对应信息区提供的编辑入口；组织任职和权限有误时联系管理员。

- 「我的成绩记录」：查看成绩概览及加减分明细。

- 「消息通知」：查看站内消息及已读状态。

- 「审批指南」：查看已启用指标的加分细则和审批步骤。

「年度评价报告」「关于」等栏目仍有预览或建设中内容。「整改提升」目前是预览页面，其中上传整改证明、提交整改计划、查看历史档案等按钮尚未完成正式办理功能。

## 四、审核老师操作

### 4.1 找到要审核的申请

**入口：党委支部端 / 党委学院端 → 审核管理。**

1. 根据需要选择组织、申请人和审批状态。

2. 查找待审核记录；找不到时点击「重置筛选」，再检查列表分页。

3. 点击记录进入详情，或使用该行操作按钮；列表也支持双击进入审批。

4. 核对申请人、审批指标、申请分数、申请理由和附件材料。

5. 查看已有审批流转记录，确认前序处理意见。

附件或申请详情加载失败时，先使用页面重试或刷新功能，材料核对完整后再作出决定。

### 4.2 通过申请

1. 打开申请详情的审批操作区域。

2. 填写「核定分数」。按细则及证明材料确定，不要只看申请分数。

3. 填写「审批意见」，也可点击常用回复后再修改。

4. 点击「确认通过」。

5. 出现成功提示后，回到列表核对该环节状态。

通过示例：材料齐全，情况属实，按××细则核定×分。

### 4.3 驳回申请

1. 打开申请详情，核对不符合要求的具体内容。

2. 填写审批意见，说明原因及需要补充的材料。

3. 点击「驳回」，等待成功提示。

驳回示例：缺少活动签到证明，请补充能够证明本人参加活动的材料后重新提交。

意见应便于申请人知道如何处理，避免只填写「不通过」。

### 4.4 转交申请

1. 在申请详情的审批操作区域点击「转交」。

2. 在「转交对象」输入姓名或学号，等待搜索结果。

3. 从结果中选择正确的接收人，核对身份。

4. 填写转交意见，点击「确认转交」。

5. 等待成功提示，并核对审批流转记录。

**只输入姓名而未选中搜索结果，不能完成转交。**

### 4.5 审批状态怎么看

| 环节状态 | 说明 |
| - | - |
| 待激活 | 尚未进入正常处理阶段的环节 |
| 待处理 | 等待处理的环节 |
| 已通过 | 本环节已同意 |
| 已驳回 | 本环节已驳回 |
| 已跳过 | 本环节未执行而被流程跳过 |


当前页面对「待激活 / 待处理」状态提供审批操作，实际是否允许提交仍以系统权限和服务端校验为准。已处理环节不能重复操作。

## 五、支部与学院管理

### 5.1 查看工作台

支部老师进入「党委支部端 → 工作台」，查看支部人数、党员及预备党员人数、平均分、等级分布和待审核申报。

学院老师进入「党委学院端 → 工作台」，查看学院统计及组织概览。组织概览左侧为学院组织树（学院没有下级组织时不显示），右侧列出各支部的党员、预备党员、少数民族人数与平均分；双击行或点击「查看详细」可进入对应支部成员页面。

如果统计或所属组织明显不符，请联系管理员核查账号的组织任职关系。

### 5.2 查询成员

**入口：党委支部端 → 支部管理；或党委学院端 → 学院支部管理。**

1. 页面有组织树时，选择需要查看的组织。

2. 在成员列表中搜索目标人员，必要时翻页。

3. 点击成员记录，查看成员详情及可访问的档案、成绩等信息。

目标支部没有下级组织时，页面可能只显示成员表。这两个入口的成员详情以查询为主，不提供成员资料编辑入口。

### 5.3 对成员扣分

仅在页面显示「扣分」按钮且本人具有相应权限时使用。

1. 找到目标成员，点击「扣分」。

2. 核对弹窗中的扣分对象。

3. 在「扣除分值」中输入**大于零的数值**，例如扣 2 分应填 `2`。

4. 填写具体扣分原因，核对后点击「确认扣分」。

\*\*扣分提交后立即生效，无需审批。\*\*处理范围限本人有权限的下级组织成员。完成后可在成绩记录中核对。

### 5.4 配置加分指标和审批步骤

**入口：党委学院端 → 指标。**

指标决定党员可以选择哪些申报项目，以及申请经过哪些审批步骤。

1. 点击新增按钮，选择「所属组织」。所属组织创建后不可更改。

2. 填写「指标名称」，例如「主题党日活动」。

3. 填写「加分细则」，说明适用条件、计分规则及证明材料要求。

4. 设置启用状态，确认创建。指标编码由系统自动生成。

5. 打开指标详情，在「审批步骤」中点击「新增步骤」。

6. 选择「审批人角色」（从已有职位中选择）；如需指定具体审批人，按管理约定填写「审批人参数」。该参数为审批人工号，可指定为学生，不确定时请先向管理员核实。

7. 填写步骤说明并确认，按实际流程依次添加后续步骤。步骤编号由系统按顺序生成。

8. 检查指标所属组织、细则、审批人员及步骤是否完整，再投入使用。

停用指标后，该指标不再参与新的审批流程。删除指标会同时删除关联审批步骤且不可恢复；删除单独步骤也不可恢复。

## 六、学校党委操作

### 6.1 查看总览与组织概览

- 「总览」：查看学校整体统计和各二级党委排名；点击排名可跳转并定位相应组织。

- 「组织概览」：在左侧选择组织，查看其下级组织的党员、预备党员人数及先锋指数平均分等统计。

### 6.2 管理组织与成员

**入口：党委学校端 → 组织成员管理。**

1. 在左侧组织树选中目标组织。

2. 新增组织时，使用「新建组织」或「新建下级」，填写名称、编码及上级组织后保存。

3. 添加成员时，点击「添加成员」，按页面填写用户 UID、职位及工作地点等信息，确认后检查列表。

4. 点击成员查看详情；使用页面提供的操作维护任职关系。

5. 需要解除成员与当前组织的关系时，点击「移除」，核对确认提示。

「移除成员」用于解除组织任职关系，与删除用户账号是不同操作。删除组织会影响其成员任职关系，请先核对组织及下级关系。

若成员行提供「重置密码」，核对姓名后执行，记录结果窗口中的新密码并通过适当方式交给本人。窗口关闭后无法再次查看这次生成的明文密码。

### 6.3 管理岗位与系统权限

「岗位管理」用于维护职位编码、名称、所属组织和适用范围。点击「新建职位」，填写页面必填项后保存；职位编码创建后不可修改。

「系统权限管理」用于维护角色和权限。在角色列表中选择角色，进入「分配权限」，设置所需权限及数据范围后保存。

| 数据范围 | 含义 |
| - | - |
| 仅本人 | 访问本人拥有的数据 |
| 本组织 | 访问本人所在组织的数据 |
| 本组织及下级 | 访问本人所在组织及其下级组织的数据 |
| 全部数据 | 访问全部数据 |
| 自定义 | 按指定组织 ID 配置访问范围 |


岗位决定组织中的任职信息，系统角色决定可使用的功能；两者需要分别维护。只添加组织职位，不代表已经授予相应系统角色。

## 七、系统管理员操作

### 7.1 新建和维护用户

**入口：管理端 → 用户与账户。**

1. 点击「新建用户」，填写用户名和基本资料。

2. 根据需要填写初始密码。

3. 添加至少一条任职信息，选择组织、职位，填写工作地点等信息。

4. 提交创建，按结果提示记录账号信息。

5. 进入用户编辑页核实并配置系统角色，保存后交由用户登录验证。

未填写初始密码时，由系统生成随机密码且不会回显；请在用户列表执行「重置密码」取得新密码。维护已有用户时，资料、角色及任职关系按各自区域的保存按钮提交。

删除用户前，需要先移除其全部组织任职关系。删除操作不可恢复。

### 7.2 批量新增用户

**入口：管理端 → 用户与账户 → 批量新增。**

1. 按弹窗说明准备 CSV 文本，固定列顺序如下。

2. 将文本粘贴到「CSV 输入」。

3. 点击「解析预览」，检查每行用户名、性别和任职信息，修正校验错误。

4. 确认无误后点击「提交创建」，查看结果。

```
username,password,name,gender,org,pos,workplaces  
example001,,示例用户,male,5,teacher,教学楼
```

示例中的组织 `5`、职位 `teacher` 均需替换成系统中实际存在且适用的值，不可直接照抄使用。

- 性别填写 `male` 或 `female`。

- `org` 填组织数字 ID，`pos` 填职位编码。

- 多条任职的 `org`、`pos`、`workplaces` 使用 `|` 分隔，各项数量须相同并逐一对应。

- 密码留空时，创建后需逐人重置密码以取得可交付的密码。

- 一次提交的任一条记录失败会导致整批回滚，修正问题后重新操作。

### 7.3 角色、组织和岗位

管理端「角色权限」「组织架构」「岗位管理」的操作方式分别参照第六章。授权后应使用目标用户身份核实可见入口和数据范围，避免只根据管理员自己的页面判断。

## 八、常见问题

| 遇到的问题 | 处理方式 |
| - | - |
| 登录提示账号或密码错误 | 检查用户名、密码和输入法；仍无法登录时联系管理员 |
| 提示账号已停用 | 联系管理员核查账号状态 |
| 首次改密窗口关不掉 | 填写当前初始密码及两次新密码，成功提交后才能继续 |
| 看不到审核管理或指标菜单 | 检查左上角工作端，再联系管理员核查角色和权限 |
| 看不到本支部或成员 | 清除筛选条件并刷新；请管理员核查组织任职关系及数据范围 |
| 申报类型下拉框为空 | 清除搜索词并重试；请学院管理员检查是否配置了可用且启用的指标 |
| 搜索后没有立即出现结果 | 等待搜索完成；申报类型搜索在停止输入约 1 秒后发起 |
| 上传材料后没有申报记录 | 确认附件上传成功，并点击「我要申报」，以成功提示及记录为准 |
| 通过了一次，申请仍在审核中 | 检查是否还有后续审批环节，等待整条流程完成 |
| 找不到审核记录 | 清除组织、申请人和状态筛选，检查分页；必要时核查审批人员配置 |
| 提示已处理或已转交 | 刷新列表查看最新状态，避免重复审批 |
| 提示无权限或 HTTP 403 | 记录当前功能和完整提示，联系管理员核查授权；改密时也需检查旧密码是否正确 |
| 页面提示网络错误或服务不可达 | 检查网络，稍后重试；仍失败时上报完整错误信息 |
| 点击提交后不确定是否成功 | 先刷新列表核对是否已有记录，再决定是否重试，避免重复提交 |
| 整改、报告等按钮提示建设中 | 属于当前版本尚未开放的功能，暂不能通过该按钮办理 |
